# web-sitesi-bakim-ve-guvenlik-rehberi
Web sitesi bakim ve guvenlik rehberi: sorumluluk, envanter, guncelleme dongusu, destek suresi biten yazilim, acil guvenlik duyurusunda ilk 48 saat, yedek ve geri yukleme testi, hesaplar, sertifika, izleme, supheli durumda ilk 24 saat, KVKK ve 20 maddelik kontrol listesi. Egitici, markdown.
